## プロダクト: **ツミキリ（Tsumikiri）**

### コンセプト

中小企業の経営者が毎日を抱える「事務作業の山」をAIが片付けるツール。

**解決する"詰み"**: 経営者が本来やるべき仕事（営業・顧客対応・戦略）に時間を使えず、見積書作成・請求書管理・メール返信・日報集計などの事務作業に忙殺されている状態。

**プロダクト概要**:
- Webアプリ（スマホ対応）
- 自然言語で指示 → AIが事務作業を実行
- 例: 「先月の売上をまとめて」→ CSVから自動集計・レポート生成
- 例: 「○○社への見積書を作って」→ テンプレートから自動生成
- 例: 「今週届いたメールを要約して」→ 重要度別に整理

**ビジネスモデル**:
- 基本無料（月10タスクまで）
- Pro: ¥2,980/月（無制限タスク + テンプレート）
- BYOK対応（自分のAPIキーを使えば無料枠拡大）

**ターゲットユーザー**:
- 従業員5〜30名の中小企業経営者
- 事務スタッフを雇う余裕がない、または雇っても追いつかない
- ITツールは使えるが、プログラミングはできない

### 技術スタック（案）

- フロントエンド: React + TypeScript + Tailwind CSS
- バックエンド: Cloudflare Workers
- データベース: Supabase
- AI: OpenAI API / Anthropic API（BYOK対応）
- ホスティング: Cloudflare Pages

## プロダクト展開ロードマップ（複数プロダクト戦略）

TOPPA Inc.は単一プロダクトの会社ではない。段階的に価値の高いプロダクトを投入していく。

| 順番 | プロダクト | 解決する"詰み" | 経営者の痛み | 狙い |
|------|-----------|---------------|-------------|------|
| 第1弾 | ツミキリ（事務AI） | 事務作業の山 | 中 | 信頼構築。AIで仕事が楽になる体験を提供 |
| 第2弾 | 集客AI（仮） | 客が来ない | 高 | 売上直結。経営者が最も金を払いたい課題 |
| 第3弾以降 | AI選手が自律的に企画 | TBD | TBD | PdMが市場調査→企画→CEO承認で自律展開 |

**原則**: 各プロダクトの企画はAI社員（PdM）が自律的に判断する。人間からの指示は不要。

## リスクと対策

| リスク | 対策 |
|--------|------|
| 経営者の"詰み"のリサーチ不足 | PdMがnote/X/Redditで経営者の声を収集 |

| コンテンツが技術者向けになる | CMOが経営者目線でレビュー必須 |
