     │                                         │

     │                                          │
     ├─▶ [Auth Handler] ──▶ Supabase Auth ────┤

     │         ▼                                │

     │    │                                     │
     │    ├─▶ ユーザーがAPIキー持有の場合        │
     │    │     └─▶ 直接AI Providerへリクエスト │
     │    │                                     │
     │    └─▶ TOPPA管理キーの場合               │
     │          └─▶ Managed AI Poolへリクエスト│
     │                                          │
     ▼                                          │

     │
     ▼
[AI応答をFrontendへ返回]
