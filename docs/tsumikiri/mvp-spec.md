# ツミキリ MVPプロダクト仕様書

> 作成者: PdM キム・スジン
> 日付: 2026-02-16
> ステータス: 詳細化中

## 1. プロダクト概要

ツミキリは、中小企業の経営者が「事務作業の山」から解放されるためのAIアシスタント。自然言語で指示するだけで、日常の事務作業をAIが代行する。

## 2. MVP機能定義

Q1四半期計画に基づき、以下の3つのMVP機能を定義する。

### 2.1. AIレポート生成

- **機能概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することでAIがデータを分析し、レポートを生成する。
- **ユーザーストーリー**:
    - 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
    - 経営者として、月ごとの売上推移をグラフで表示してほしい。事業の状況を視覚的に把握するため。
    - 経営者として、部門別の利益率を分析してほしい。どの部門に注力すべきか判断するため。
    - 経営者として、生成されたレポートをPDFでダウンロードしたい。社内共有や報告に使うため。
    - 経営者として、過去に生成したレポートを一覧で確認したい。後から参照できるようにするため。
    - 経営者として、レポート生成時に使用するデータ範囲（例: 特定の期間、特定の顧客）を指定したい。必要な情報だけを抽出するため。
    - 経営者として、AIが生成したレポートの内容について、「この部分をもっと詳しく説明して」と追加で質問したい。レポート内容を深く理解し、疑問点を解消するため。
    - 経営者として、定期的に（例: 毎月1日）特定のCSVファイルから自動でレポートを生成し、メールで受け取りたい。定型業務を自動化し、報告漏れを防ぐため。
    - 経営者として、生成されたレポートを、グラフの種類（棒グラフ、円グラフなど）や表示項目を自由にカスタマイズして出力したい。見せたい情報に合わせて柔軟に調整するため。
    - 経営者として、Excelファイルをアップロードして、「このシートのデータを使って、商品Aと商品Bの売上を比較して」と指示したい。異なるフォーマットのデータも扱えるようにするため。
    - 経営者として、アップロードしたExcelファイルに複数のシートがある場合、どのシートを分析対象にするか指定したい。不要なシートのデータを含めないようにするため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - レポート生成機能への導線ボタン
        - 過去のレポート履歴へのリンク
    2.  `レポート生成トップ`:
        - 「ファイルをアップロードしてレポートを生成」ボタン
        - 「過去のレポートを見る」ボタン
    3.  `ファイルアップロード画面`:
        - ドラッグ＆ドロップまたはファイル選択によるCSV/Excelファイルアップロードエリア
        - アップロード可能なファイル形式とサイズ上限の表示（例: CSV, XLSX, 最大10MB）
        - アップロードされたファイルのプレビュー（ファイル名、シート名、最初の数行のデータ）
        - 「次へ」ボタン
    4.  `分析指示入力画面`:
        - 自然言語での分析指示入力テキストエリア（例: 「先月の売上を部門別にまとめて」）
        - 指示の具体例やヒントの表示
        - 「レポート生成」ボタン
    5.  `レポート表示画面`:
        - AIが生成したレポートの表示エリア（テキスト、グラフ、表など）
        - PDF/Markdownダウンロードボタン
        - 「このレポートについて質問する」ボタン（チャットアシスタントへの連携）
    6.  `レポート履歴画面`:
        - 過去に生成されたレポートの一覧表示（タイトル、生成日時、使用ファイル名）
        - 各レポートの詳細画面へのリンク
- **データモデル**:
    - `reports`:
        - `report_id` (PK)
        - `user_id` (FK)
        - `title`
        - `file_name` (アップロードされたファイル名)
        - `file_url` (Supabase StorageなどへのURL)
        - `prompt` (ユーザーの分析指示)
        - `result` (AIが生成したレポート内容)
        - `format` (PDF/Markdownなど)
        - `created_at`
- **APIエンドポイント**:
    - `POST /api/report/upload`:
        - リクエスト: ファイルデータ
        - レスポンス: `{ "file_url": "...", "file_name": "..." }`
        - 機能: CSV/Excelファイルをストレージにアップロードし、URLを返す。
    - `POST /api/report/generate`:
        - リクエスト: `{ "file_url": "...", "prompt": "..." }`
        - レスポンス: `{ "report_id": "...", "result": "..." }`
        - 機能: アップロードされたファイルと指示に基づき、AIがレポートを生成。
    - `GET /api/report/history/{user_id}`:
        - レスポンス: `[ { "report_id": "...", "title": "...", "created_at": "..." } ]`
        - 機能: 特定ユーザーのレポート履歴を一覧で取得。
    - `GET /api/report/{report_id}`:
        - レスポンス: `{ "report_id": "...", "title": "...", "result": "..." }`
        - 機能: 特定のレポート詳細を取得。
- **非機能要件**:
    - **ファイルサイズ**: アップロード可能なファイルは最大10MBとする。
    - **処理時間**: レポート生成は30秒以内とする（ファイルの複雑度による）。
    - **対応形式**: CSV, XLSXに対応。
    - **データ保持**: アップロードされたファイルおよび生成されたレポートは最低90日間保持する。

### 2.2. テンプレート書類生成

- **機能概要**: 見積書・請求書・お礼状などのテンプレートを元に、自然言語で指示するだけでAIが自動で書類を生成する。
- **ユーザーストーリー**:
    - 経営者として、「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」と言いたい。書類作成に30分かかるのを3分にするため。
    - 経営者として、よく使う書類のテンプレートを登録したい。毎回ゼロから作成する手間を省くため。
    - 経営者として、AIが作った書類をプレビューしてから確定したい。間違いがあると信用問題だから。
    - 経営者として、生成された書類をPDFでダウンロードしたい。顧客への送付や社内保管に使うため。
    - 経営者として、過去に生成した書類を検索・閲覧したい。「先月の○○社の見積書どこだっけ？」をなくすため。
    - 経営者として、生成された書類をメールに添付して直接送信したい（Phase 2）。手動でメール作成・添付する手間を省くため。
    - 経営者として、書類生成時に、顧客情報や商品情報を自動で補完してほしい。入力の手間を減らすため。
    - 経営者として、書類の項目（日付、宛名、金額など）をAIが自動で判断し、適切な場所に挿入してほしい。フォーマット崩れを防ぐため。
    - 経営者として、複数のテンプレートを組み合わせて、新しい種類の書類を作成したい。柔軟な書類作成を可能にするため。
    - 経営者として、書類生成時に必要な情報が不足している場合、AIがそれを教えてほしい。手戻りを防ぎ、正確な書類を作成するため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - 書類生成機能への導線ボタン
        - 過去の書類履歴へのリンク
    2.  `書類生成トップ`:
        - テンプレート選択エリア（見積書、請求書、お礼状など）
        - 「テンプレートを新規作成」ボタン
        - 「過去の書類を見る」ボタン
    3.  `テンプレート選択画面`:
        - 既存テンプレートの一覧表示
        - テンプレートのプレビュー
        - 「このテンプレートで作成」ボタン
    4.  `情報入力画面`:
        - 自然言語での指示入力テキストエリア（例: 「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」）
        - フォーム形式での情報入力オプション（宛名、金額、商品名など）
        - 「プレビュー」ボタン
    5.  `書類プレビュー画面`:
        - AIが生成した書類のプレビュー表示
        - 編集機能（軽微な修正）
        - PDFダウンロードボタン
        - 「確定して保存」ボタン
    6.  `書類履歴画面`:
        - 過去に生成された書類の一覧表示（タイトル、生成日時、顧客名）
        - 各書類の詳細画面へのリンク
- **データモデル**:
    - `templates`:
        - `template_id` (PK)
        - `user_id` (FK)
        - `template_name`
        - `template_content` (Markdown or HTML)
        - `created_at`
    - `documents`:
        - `document_id` (PK)
        - `user_id` (FK)
        - `template_id` (FK)
        - `title`
        - `content` (生成された書類の内容)
        - `pdf_url` (生成されたPDFのURL)
        - `created_at`
- **APIエンドポイント**:
    - `GET /api/templates`:
        - レスポンス: `[ { "template_id": "...", "template_name": "...", "preview_url": "..." } ]`
        - 機能: 利用可能なテンプレートを一覧で取得。
    - `POST /api/document/generate`:
        - リクエスト: `{ "template_id": "...", "prompt": "...", "data": { ... } }`
        - レスポンス: `{ "document_id": "...", "preview_url": "..." }`
        - 機能: テンプレートと指示に基づき、AIが書類を生成しプレビューURLを返す。
    - `POST /api/document/{document_id}/confirm`:
        - リクエスト: なし
        - レスポンス: `{ "status": "success", "pdf_url": "..." }`
        - 機能: 生成された書類を確定し、PDFを生成・保存。
    - `GET /api/document/history/{user_id}`:
        - レスポンス: `[ { "document_id": "...", "title": "...", "created_at": "..." } ]`
        - 機能: 特定ユーザーの書類履歴を一覧で取得。
- **非機能要件**:
    - **生成速度**: 書類生成は10秒以内とする。
    - **テンプレート数**: 初期は5種類程度のテンプレートを用意。
    - **編集機能**: プレビュー画面での軽微なテキスト修正に対応。
    - **データ保持**: 生成された書類およびテンプレートは最低90日間保持する。

### 2.3. チャットアシスタント

- **機能概要**: 経営者のあらゆる質問や相談にAIがチャット形式で回答し、情報提供やアドバイスを行う。過去の会話履歴を保持し、文脈に応じた応答が可能。
- **ユーザーストーリー**:
    - 経営者として、何でも聞けるAIチャットで事業に関する質問や相談をしたい。経営判断の参考にしたいから。
    - 経営者として、AIにビジネスメールの作成を手伝ってほしい。文章作成の時間を短縮するため。
    - 経営者として、過去の会話履歴をAIが覚えていてほしい。同じことを何度も説明する手間を省くため。
    - 経営者として、スマホアプリのように直感的にチャットを使いたい。場所を選ばずに利用するため。
    - 経営者として、AIからの回答が根拠に基づいているか確認したい。誤った情報で判断しないため。
    - 経営者として、AIとの会話中にファイル（例: 議事録PDF）をアップロードして、その内容について質問したい。資料に基づいた具体的なアドバイスを得るため。
    - 経営者として、AIが提案してくれた内容をワンクリックでタスク管理ツール（例: Trello）に連携したい。次のアクションをスムーズに進めるため。
    - 経営者として、AIに生成させた文章（メール下書きなど）を、そのままコピーして他のアプリに貼り付けたい。手動での転記作業をなくすため。
    - 経営者として、AIチャットの会話内容をPDFでエクスポートしたい。社内共有や記録として残すため。
    - 経営者として、AIチャットで過去の会話をキーワードで検索したい。特定の情報やアドバイスを素早く見つけ出すため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - チャット機能への導線ボタン
        - 最新のチャット履歴プレビュー
    2.  `チャット画面`:
        - AIとの会話履歴表示エリア
        - メッセージ入力フォーム
        - 送信ボタン
        - 音声入力ボタン（Phase 2）
        - ファイルアップロードボタン: メッセージ入力フォームの横に配置。クリックするとファイル選択ダイアログが開く。
        - AI提案アクション表示エリア: AIからの返答に付随する提案（例: 「Trelloに連携」ボタン）を表示するエリア。
        - 会話エクスポートボタン: 会話履歴表示エリアの上部または下部に配置。クリックするとPDFエクスポートオプションが表示される。
        - 会話検索バー: 会話履歴表示エリアの上部に配置。キーワード入力で過去の会話をフィルタリング。
- **データモデル**:
    - `chat_sessions`:
        - `session_id` (PK)
        - `user_id` (FK)
        - `created_at`
        - `updated_at`
    - `chat_messages`:
        - `message_id` (PK)
        - `session_id` (FK)
        - `role` (user/assistant/system)
        - `content`
        - `timestamp`
        - `attached_file_url` (TEXT): メッセージに添付されたファイルのURL（Supabase StorageのURLなど）
        - `action_suggested` (JSONB): AIが提案したアクションの内容（例: `{ "type": "trello_card", "payload": { "title": "...", "description": "..." } }`）
- **APIエンドポイント**:
    - `POST /api/chat`:
        - リクエスト: `{ "session_id": "...", "message": "...", "attached_file_url": "...", "attached_file_type": "..." }`
        - レスポンス: `{ "reply": "...", "session_id": "...", "suggested_actions": [ { "type": "...", "payload": { "..." } } ] }`
        - 機能: ユーザーメッセージを送信し、AIの応答を取得する。セッションIDを指定することで会話履歴を継続する。添付ファイル情報を含める。AIからの提案アクションも返す。
    - `GET /api/chat/history/{user_id}`:
        - リクエスト: なし
        - レスポンス: `[ { "session_id": "...", "last_message": "...", "updated_at": "..." } ]`
        - 機能: 特定ユーザーのチャットセッション履歴を一覧で取得する。
    - `GET /api/chat/session/{session_id}`:
        - リクエスト: なし
        - レスポンス: `[ { "role": "...", "content": "...", "timestamp": "...", "attached_file_url": "...", "action_suggested": { "..." } } ]`
        - 機能: 特定のチャットセッションの全メッセージ履歴を取得する。添付ファイル情報や提案アクションも含む。
    - `POST /api/chat/action/trello`:
        - リクエスト: `{ "session_id": "...", "action_type": "trello_card", "payload": { "title": "...", "description": "..." } }`
        - レスポンス: `{ "status": "success", "trello_card_url": "..." }`
        - 機能: AIが提案したTrelloカード作成アクションを実行する。
    - `GET /api/chat/export/{session_id}/pdf`:
        - リクエスト: なし
        - レスポンス: PDFバイナリデータ
        - 機能: 特定セッションの会話履歴をPDF形式でエクスポートする。
    - `GET /api/chat/history/{user_id}?search={keyword}`:
        - リクエスト: `{ "search": "キーワード" }`
        - レスポンス: 検索結果に合致するセッションまたはメッセージのリスト
        - 機能: キーワードでチャット履歴を検索する。
- **非機能要件**:
    - **応答速度**: AI応答は3秒以内とする。
    - **履歴保持**: 会話履歴は最低90日間保持する。
    - **セキュリティ**: 会話内容は暗号化して保存する。
    - **多言語対応**: 初期は日本語のみ。将来的には英語対応を検討。
    - **ファイル対応**: PDF, DOCX, XLSX, TXTファイルなど、一般的なビジネス文書フォーマットのアップロードに対応。ファイルサイズ上限は10MBとする。
    - **外部連携**: Trello, Google Calendarなどの外部SaaSとの連携を将来的に検討。初期MVPではコピー＆ペーストによる連携を推奨。
    - **検索精度**: キーワード検索において、会話内容の関連性の高いメッセージを正確に表示する。
