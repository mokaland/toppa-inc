## 3. 機能詳細

### MVP-1: AIレポート生成

#### 3.1.1 ユーザーストーリー
- 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。

#### 3.1.2 UIコンポーネント
- ファイルアップロードエリア（ドラッグ＆ドロップ対応）
- 指示入力用のテキストエリア
- 「生成」ボタン
- レポート表示エリア（Markdown形式）
- 「ダウンロード」ボタン（Markdown）
- ローディングスピナー

#### 3.1.3 動作要件
1.  ユーザーはCSVファイルをアップロードする。
2.  ファイルアップロード後、プレビューとして先頭5行が表示される。
3.  ユーザーは「先月の売上を部門別にグラフ化して」のような自然言語で指示を入力する。
4.  「生成」ボタンを押すと、バックエンドにファイルと指示が送信される。
5.  バックエンドはAI（LLM）を用いてデータを分析・集計し、結果をMarkdown形式のレポートとして生成する。
6.  生成されたレポートがフロントエンドの表示エリアに表示される。
7.  ユーザーはレポートをMarkdown形式でダウンロードできる。

#### 3.1.4 エラーハンドリング
- 対応していないファイル形式がアップロードされた場合、「対応しているファイル形式はCSVのみです」と表示する。
- ファイルサイズが5MBを超える場合、「ファイルサイズは5MB以下にしてください」と表示する。
- AIの処理でエラーが発生した場合、「レポートの生成に失敗しました。もう一度お試しください」と表示する。
