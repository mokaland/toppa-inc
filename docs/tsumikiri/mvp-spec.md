## 1. プロダクト概要

ツミキリは、中小企業の経営者が「事務作業の山」から解放されるためのAIアシスタント。自然言語で指示するだけで、日常の事務作業をAIが代行する。

## 2. MVP機能定義

Q1四半期計画に基づき、以下の3つのMVP機能を定義する。

### 2.1. AIレポート生成

- **機能概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することでAIがデータを分析し、レポートを生成する。
- **ユーザーストーリー**:
    - 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
    - 経営者として、月ごとの売上推移をグラフで表示してほしい。事業の状況を視覚的に把握するため。
    - 経営者として、部門別の利益率を分析してほしい。どの部門に注力すべきか判断するため。
    - 経営者として、生成されたレポートをPDFでダウンロードしたい。社内共有や報告に使うため。
    - 経営者として、過去に生成したレポートを一覧で確認したい。後から参照できるようにするため。
    - 経営者として、レポート生成時に使用するデータ範囲（例: 特定の期間、特定の顧客）を指定したい。必要な情報だけを抽出するため。
    - 経営者として、AIが生成したレポートの内容について、「この部分をもっと詳しく説明して」と追加で質問したい。レポート内容を深く理解し、疑問点を解消するため。
    - 経営者として、定期的に（例: 毎月1日）特定のCSVファイルから自動でレポートを生成し、メールで受け取りたい。定型業務を自動化し、報告漏れを防ぐため。
    - 経営者として、生成されたレポートを、グラフの種類（棒グラフ、円グラフ、折れ線グラフなど）や表示項目を自由にカスタマイズして出力したい。見せたい情報に合わせて柔軟に調整するため。
    - 経営者として、Excelファイルをアップロードして、「このシートのデータを使って、商品Aと商品Bの売上を比較して」と指示したい。異なるフォーマットのデータも扱えるようにするため。
    - 経営者として、アップロードしたExcelファイルに複数のシートがある場合、どのシートを分析対象にするか指定したい。不要なシートのデータを含めないようにするため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - レポート生成機能への導線ボタン
        - 過去のレポート履歴へのリンク
    2.  `レポート生成トップ`:
        - 「ファイルをアップロードしてレポートを生成」ボタン
        - 「過去のレポートを見る」ボタン
    3.  `ファイルアップロード画面`:
        - ドラッグ＆ドロップまたはファイル選択によるCSV/Excelファイルアップロードエリア
        - アップロード可能なファイル形式とサイズ上限の表示（例: CSV, XLSX, 最大10MB）
        - アップロードされたファイルのプレビュー（ファイル名、シート名、最初の数行のデータ）
        - 「次へ」ボタン
    4.  `分析指示入力画面`:
        - 自然言語での分析指示入力テキストエリア（例: 「先月の売上を部門別にまとめて」）
        - 指示の具体例やヒントの表示
        - 「レポート生成」ボタン
    5.  `レポート表示画面`:
        - AIが生成したレポートの表示（テキスト、グラフなど）
        - PDF/Markdownダウンロードボタン
        - 「追加で質問する」ボタン（チャットアシスタント連携）
        - 「他のレポートを見る」ボタン

### 2.2. テンプレート書類生成

- **機能概要**: 見積書、請求書、お礼状などのテンプレートを元に、自然言語またはフォーム入力で情報を与えることでAIが書類を自動生成する。
- **ユーザーストーリー**:
    - 経営者として、見積書テンプレートを使って、取引先名と金額を入力するだけで見積書を作成したい。手作業での入力ミスをなくすため。
    - 経営者として、作成した請求書をPDF形式でダウンロードし、メールで取引先に送りたい。郵送の手間を省くため。
    - 経営者として、複数のテンプレート（見積書、請求書、お礼状など）を自由に切り替えて使用したい。様々なビジネスシーンに対応するため。
    - 経営者として、AIが生成した書類の内容をプレビューで確認し、必要に応じて修正してから確定したい。誤字脱字や金額の間違いを防ぐため。
    - 経営者として、よく使う取引先情報や商品情報を登録しておき、書類生成時に自動で入力されるようにしたい。毎回入力する手間を省くため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - 書類生成機能への導線ボタン
        - 過去の書類履歴へのリンク
    2.  `書類生成トップ`:
        - テンプレート選択（見積書、請求書、お礼状など）
        - 「新しい書類を作成」ボタン
        - 「過去の書類を見る」ボタン
    3.  `情報入力画面`:
        - 選択したテンプレートに応じた入力フォーム
        - 自然言語での入力エリア（例: 「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」）
        - 登録済みの取引先・商品情報の選択/入力補助
        - 「プレビュー」ボタン
    4.  `プレビュー・編集画面`:
        - AIが生成した書類のプレビュー表示
        - テキスト編集、項目修正機能
        - 「PDF出力」ボタン
        - 「メールで送信」ボタン（Phase 2）
        - 「保存して終了」ボタン

### 2.3. チャットアシスタント

- **機能概要**: 何でも聞ける経営者向けAIチャット。事業に関する質問、アドバイス、文章作成など、経営者の"詰み"に特化したシステムプロンプトで応答する。過去の会話履歴を保持する。
- **ユーザーストーリー**:
    - 経営者として、チャットで「今月の目標達成状況は？」と質問し、AIが売上データに基づいて回答してほしい。リアルタイムで状況把握するため。
    - 経営者として、チャットで「新しいキャンペーンのアイデアを出して」と依頼し、AIが提案してほしい。マーケティングのヒントを得るため。
    - 経営者として、チャットで「このメールの返信文案を作成して」と指示し、AIが丁寧な文章を作成してほしい。メール作成時間を短縮するため。
    - 経営者として、過去のチャット履歴を検索し、特定の会話を素早く見つけたい。以前の相談内容を振り返るため。
    - 経営者として、チャットでファイル（PDFや画像）を共有し、「この資料を要約して」と指示したい。長文を読む時間を節約するため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - チャットアシスタント機能への導線ボタン
    2.  `チャット画面`:
        - 会話履歴の表示
        - テキスト入力エリア
        - 音声入力ボタン（Phase 2）
        - ファイル添付ボタン（Phase 2）
        - 「送信」ボタン
        - よくある質問や提案のショートカット表示
    3.  `会話履歴画面`（チャット画面から遷移）:
        - 過去の会話セッション一覧
        - 会話内容の検索機能
        - 特定の会話セッションの再開

## 4. 非機能要件

- **レスポンス**: チャット応答3秒以内、レポート/書類生成5秒以内
- **可用性**: 99.5%以上
- **セキュリティ**: データ暗号化（at-rest, in-transit）、SOC2準拠を目指す
- **対応ブラウザ**: Chrome, Safari, Edge（最新2バージョン）
- **スマホ**: iOS Safari, Android Chrome 対応
- **スケーラビリティ**: アクティブユーザー1,000名まで対応可能なアーキテクチャ
- **BYOK対応**: ユーザーが自身のAIプロバイダーAPIキーを設定し、利用可能にする
