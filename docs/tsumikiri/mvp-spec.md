## 1. プロダクト概要

ツミキリは、中小企業の経営者が「事務作業の山」から解放されるためのAIアシスタント。自然言語で指示するだけで、日常の事務作業をAIが代行する。

## 2. MVP機能定義

Q1四半期計画に基づき、以下の3つのMVP機能を定義する。

### 2.1. AIレポート生成

- **機能概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することでAIがデータを分析し、レポートを生成する。
- **ユーザーストーリー**:
    - 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
    - 経営者として、月ごとの売上推移をグラフで表示してほしい。事業の状況を視覚的に把握するため。
    - 経営者として、部門別の利益率を分析してほしい。どの部門に注力すべきか判断するため。
    - 経営者として、生成されたレポートをPDFでダウンロードしたい。社内共有や報告に使うため。
    - 経営者として、過去に生成したレポートを一覧で確認したい。後から参照できるようにするため。
    - 経営者として、レポート生成時に使用するデータ範囲（例: 特定の期間、特定の顧客）を指定したい。必要な情報だけを抽出するため。
    - 経営者として、AIが生成したレポートの内容について、「この部分をもっと詳しく説明して」と追加で質問したい。レポート内容を深く理解し、疑問点を解消するため。
    - 経営者として、定期的に（例: 毎月1日）特定のCSVファイルから自動でレポートを生成し、メールで受け取りたい。定型業務を自動化し、報告漏れを防ぐため。
    - 経営者として、生成されたレポートを、グラフの種類（棒グラフ、円グラフなど）や表示項目を自由にカスタマイズして出力したい。見せたい情報に合わせて柔軟に調整するため。
    - 経営者として、Excelファイルをアップロードして、「このシートのデータを使って、商品Aと商品Bの売上を比較して」と指示したい。異なるフォーマットのデータも扱えるようにするため。
    - 経営者として、アップロードしたExcelファイルに複数のシートがある場合、どのシートを分析対象にするか指定したい。不要なシートのデータを含めないようにするため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - レポート生成機能への導線ボタン
        - 過去のレポート履歴へのリンク
    2.  `レポート生成トップ`:
        - 「ファイルをアップロードしてレポートを生成」ボタン
        - 「過去のレポートを見る」ボタン
    3.  `ファイルアップロード画面`:
        - ドラッグ＆ドロップまたはファイル選択によるCSV/Excelファイルアップロードエリア
        - アップロード可能なファイル形式とサイズ上限の表示（例: CSV, XLSX, 最大10MB）
        - アップロードされたファイルのプレビュー（ファイル名、シート名、最初の数行のデータ）
        - 「次へ」ボタン
    4.  `分析指示入力画面`:
        - 自然言語での分析指示入力テキストエリア（例: 「先月の売上を部門別にまとめてください」）
        - 指示例の提示
        - 「レポートを生成」ボタン
    5.  `レポート表示画面`:
        - 生成されたレポートの表示（Markdown形式）
        - PDF/Markdownダウンロードボタン
        - レポート内容に関する追加質問入力エリア
        - グラフの種類、表示項目カスタマイズオプション
    6.  `レポート履歴画面`:
        - 過去のレポート一覧（タイトル、生成日時、ファイル名）
        - 各レポートの詳細表示リンク
- **データモデル**:
    - `reports`テーブル: `id`, `user_id`, `title`, `file_name`, `file_url`, `prompt`, `result`, `created_at`, `updated_at`
    - `report_files`テーブル: `id`, `report_id`, `file_path`, `original_file_name`, `file_type`, `uploaded_at`
- **APIエンドポイント**:
    - `POST /api/report/upload`: ファイルアップロード
    - `POST /api/report/generate`: レポート生成指示
    - `GET /api/report/history`: レポート履歴取得
    - `GET /api/report/:id`: 特定レポート詳細取得
- **非機能要件**:
    - レポート生成時間: ファイルサイズによるが、最大60秒以内
    - 対応ファイル形式: CSV, XLSX
    - ファイルサイズ上限: 10MB
    - データ保持期間: Freeプラン30日、Proプラン90日

### 2.2. テンプレート書類生成

- **機能概要**: 見積書・請求書・お礼状などのテンプレートを用意し、自然言語で情報を入力することでAIが書類を生成する。
- **ユーザーストーリー**:
    - 経営者として、「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」と指示したい。書類作成に30分かかるのを3分にするため。
    - 経営者として、請求書を自動で作成してほしい。毎月の定型業務を効率化するため。
    - 経営者として、お礼状や挨拶文のテンプレートを使って、顧客ごとに内容を少し変更して生成したい。個別対応の質を保ちつつ、時間を節約するため。
    - 経営者として、生成された書類をPDFでプレビューしてから確定したい。間違いがあると信用問題だから。
    - 経営者として、生成された書類をメールに添付してそのまま送信したい。さらに業務を簡略化するため。
    - 経営者として、よく使う取引先情報や商品情報を事前に登録しておきたい。入力の手間を省くため。
    - 経営者として、複数のテンプレートの中から目的に合ったものを選びたい。用途に応じて最適な書類を作成するため。
    - 経営者として、既存のテンプレートをベースに、自社独自の項目を追加してカスタマイズしたい。柔軟な書類作成を可能にするため。
    - 経営者として、書類生成時に必要な情報が不足している場合、AIから不足情報の入力を促してほしい。スムーズに書類を完成させるため。
    - 経営者として、過去に生成した書類を検索・閲覧したい。「先月の○○社の見積書どこだっけ？」をなくすため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - 書類生成機能への導線ボタン
        - 過去の書類履歴へのリンク
    2.  `書類生成トップ`:
        - テンプレート選択（見積書、請求書、お礼状など）
        - 「過去の書類を見る」ボタン
    3.  `情報入力画面`:\
        - 選択したテンプレートに基づいた自然言語入力テキストエリア（例: 「○○社への見積書を作って…」）
        - またはフォーム形式での入力補助（宛先、金額、品目など）
        - 「書類を生成」ボタン
    4.  `プレビュー・編集画面`:
        - 生成された書類のプレビュー表示
        - テキストベースでの簡易編集機能
        - 「PDF出力」ボタン
        - 「メール送信」ボタン（Phase 2）
    5.  `書類履歴画面`:
        - 過去の書類一覧（タイトル、生成日時、取引先名）
        - 各書類の詳細表示リンク
- **データモデル**:
    - `documents`テーブル: `id`, `user_id`, `template_id`, `title`, `content`, `generated_at`, `updated_at`
    - `templates`テーブル: `id`, `name`, `type`, `content_template`, `created_at`
    - `customers`テーブル: `id`, `user_id`, `name`, `address`, `contact_info`
    - `products`テーブル: `id`, `user_id`, `name`, `price`, `description`
- **APIエンドポイント**:
    - `GET /api/templates`: テンプレート一覧取得
    - `POST /api/document/generate`: 書類生成指示
    - `GET /api/document/history`: 書類履歴取得
    - `GET /api/document/:id`: 特定書類詳細取得
- **非機能要件**:
    - 書類生成時間: 5秒以内
    - データ保持期間: Freeプラン30日、Proプラン90日
    - 出力形式: PDF

### 2.3. チャットアシスタント

- **機能概要**: 経営者の"詰み"に特化したAIチャットアシスタント。事業に関する質問、アドバイス、文章作成など、多様な事務作業や思考支援を自然言語でサポートする。過去の会話履歴を保持し、コンテキストを踏まえた応答が可能。
- **ユーザーストーリー**:
    - 経営者として、AIアシスタントに「今日のタスクを優先度順に整理して」と指示したい。日々の業務を効率化するため。
    - 経営者として、AIアシスタントに「来週の会議のアジェンダを作成して」と指示したい。会議準備の時間を短縮するため。
    - 経営者として、AIアシスタントに「新しいサービスについてブレインストーミングを手伝ってほしい」と相談したい。アイデア出しの壁打ち相手が欲しいから。
    - 経営者として、AIアシスタントに「顧客からのクレームメールの返信文案を作成してほしい」と指示したい。迅速かつ丁寧な対応をしたいから。
    - 経営者として、AIアシスタントに「従業員のパフォーマンスレビューのフィードバック文案を作成してほしい」と指示したい。公平かつ建設的なフィードバックを提供するため。
    - 経営者として、過去のチャット履歴を閲覧したい。以前の会話内容を振り返るため。
    - 経営者として、特定のチャット履歴を検索したい。必要な情報に素早くアクセスするため。
    - 経営者として、チャットアシスタントとの会話を途中で中断しても、次回再開時に前回の続きから始めたい。コンテキストが途切れないようにするため。
    - 経営者として、チャットアシスタントに「この業界の最新トレンドを教えて」と質問したい。市場の動向を把握し、戦略に活かすため。
    - 経営者として、チャットアシスタントに「この事業計画書の改善点を指摘してほしい」と依頼したい。客観的なフィードバックを得て、計画の精度を高めるため。
- **画面遷移**:
    1.  `ダッシュボード`:
        - チャットアシスタント機能への導線ボタン
    2.  `チャット画面`:
        - 会話履歴表示エリア
        - メッセージ入力テキストエリア
        - 送信ボタン
        - 音声入力ボタン（Phase 2）
        - 過去のチャット履歴へのリンク
    3.  `チャット履歴画面`:
        - 過去のチャットセッション一覧（タイトル、開始日時）
        - 各セッションの詳細表示リンク
- **データモデル**:
    - `chat_messages`テーブル: `id`, `user_id`, `role`, `content`, `created_at`
- **APIエンドポイント**:
    - `POST /api/chat`: チャットメッセージ送信、AI応答取得
    - `GET /api/chat/history`: 会話履歴取得
    - `GET /api/chat/history/:sessionId`: 特定セッションの履歴取得
- **非機能要件**:
    - レスポンス時間: 3秒以内
    - データ保持期間: Freeプラン30日、Proプラン90日
    - 対応言語: 日本語のみ

## 3. 非機能要件（共通）

- **レスポンス**: チャット応答3秒以内、レポート生成最大60秒以内、書類生成5秒以内
- **可用性**: 99.5%以上
- **セキュリティ**: データ暗号化（at-rest, in-transit）、SOC2準拠を目指す
- **対応ブラウザ**: Chrome, Safari, Edge（最新2バージョン）
- **スマホ**: iOS Safari, Android Chrome 対応
- **BYOK対応**: ユーザーが自身のAIプロバイダーAPIキーを設定可能（OpenAI, Anthropic, Google Gemini）
    - BYOK利用時は、月額料金不要でProプランの機能が利用可能。ただし、API利用料はユーザー負担。
    - 設定画面からAPIキーを登録・管理できる。
