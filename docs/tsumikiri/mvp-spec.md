## 1. プロダクト概要

ツミキリは、中小企業の経営者が日常の事務作業から解放され、本業に集中できるよう支援するAIアシスタントです。自然言語による指示で、書類作成、データ集計、チャットによる経営相談などの事務作業をAIが代行します。

## 2. ターゲットユーザー

- **職業**: 建設業の社長（従業員12名）
- **課題**: 現場監督しながら見積書・請求書・日報管理。事務員は1人だが追いつかない
- **ITリテラシー**: LINEとExcelは使える。専門ツールは苦手

## 3. 解決する"詰み"

| 詰みの種類 | 具体例 | ツミキリの解決方法 |
|-----------|--------|------------------|
| 書類作成の山 | 見積書・請求書・契約書 | テンプレート + AI自動生成 |
| データ集計 | 売上集計・日報まとめ | CSV/Excelアップロード → AI分析 |
| メール対応 | 問い合わせ・フォローアップ | AIが下書き生成 → 確認して送信 |
| 情報整理 | 会議メモ・タスク管理 | 自然言語で入力 → 自動整理 |

## 4. MVP機能詳細

Q1計画で定義されたMVP3機能について、より詳細な仕様を記述します。
Founding Engineerのカルロス・メンデスの実装計画 (`docs/implementation-plan.md`) を参照し、データベーススキーマやAPIエンドポイント設計と整合性を取ります。

### 4.1. 機能1: AIレポート生成

*   **概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することで、AIがデータを分析しレポートを生成する。
*   **ユースケース**:
    *   経営者として、月次の売上データをCSVでアップロードし、「部門別の売上をまとめて」と指示したい。
    *   経営者として、生成されたレポートをPDFでダウンロードし、社内会議で共有したい。
*   **入力**:
    *   ファイル: CSV, Excel (最大5MB, 10万行)
    *   指示: 自然言語テキスト (例: 「先月の売上を部門別にまとめてください」)
*   **出力**:
    *   分析レポート: 日本語テキスト (Markdown形式)
    *   ダウンロード形式: PDF, Markdown
*   **データモデル**: `reports` テーブル (`docs/implementation-plan.md` 参照)
    *   `id`, `user_id`, `title`, `file_name`, `file_url`, `prompt`, `result`, `status`, `created_at`, `completed_at`
*   **APIエンドポイント**: (`docs/implementation-plan.md` 参照)
    *   `POST /api/report/upload`: ファイルアップロード
    *   `POST /api/report/generate`: レポート生成要求
    *   `GET /api/report/:id`: レポート結果取得
    *   `GET /api/report/list`: レポート一覧取得

### 4.2. 機能2: テンプレート書類生成

*   **概要**: 事前に用意されたテンプレート（見積書、請求書など）を選択し、自然言語またはフォームで情報を入力することで、AIが自動的に書類を生成する。
*   **ユースケース**:
    *   経営者として、「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」と指示したい。
    *   経営者として、生成された見積書をプレビューし、問題なければPDFとして出力したい。
*   **入力**:
    *   テンプレート選択: 見積書、請求書、お礼状 (初期3種)
    *   情報: 自然言語テキスト、または項目ごとのフォーム入力
*   **出力**:
    *   生成書類: PDF
*   **データモデル**: `documents` テーブル (`docs/implementation-plan.md` 参照)
    *   `id`, `user_id`, `template_id`, `template_name`, `input_data` (JSONB), `generated_content`, `status`, `created_at`, `completed_at`
*   **テンプレート定義**: (`docs/implementation-plan.md` 参照)
    *   `estimate`: 見積書 (必須項目: 会社名、品目、数量、単価、金額)
    *   `invoice`: 請求書 (必須項目: 会社名、請求金額、支払期限)
    *   `thankyou`: お礼状 (必須項目: 会社名、顧客名)
*   **APIエンドポイント**: (`docs/implementation-plan.md` 参照)
    *   `/api/document/generate`: 書類生成要求
    *   `/api/document/list`: 生成済み書類一覧取得
    *   `/api/document/:id`: 特定書類取得

### 4.3. 機能3: チャットアシスタント

*   **概要**: 経営者の"詰み"に特化したAIチャットインターフェース。事業に関する質問、アドバイス、文章作成など、幅広い相談に対応する。過去の会話履歴を保持し、コンテキストに応じた応答が可能。
*   **ユースケース**:
    *   経営者として、「新しい事業のアイデアについて相談したい」とAIに話しかけたい。
    *   経営者として、「このメールの返信文を考えてほしい」と依頼したい。
    *   経営者として、過去の会話履歴を参照し、以前の相談内容を思い出したい。
*   **入力**:
    *   メッセージ: 自然言語テキスト
*   **出力**:
    *   AI応答: 自然言語テキスト
*   **データモデル**: `chat_messages` テーブル (`docs/implementation-plan.md` 参照)
    *   `id`, `user_id`, `role`, `content`, `created_at`
*   **APIエンドポイント**: (`docs/implementation-plan.md` 参照)
    *   `POST /api/chat`: チャット送信・AI応答取得
    *   `GET /api/chat/history`: 会話履歴取得
    *   `GET /api/chat/history/:sessionId`: 特定セッションの履歴取得

## 5. ユーザーストーリー

1.  経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
2.  経営者として、「○○社に見積書を送って」と言いたい。書類作成に30分かかるのを3分にするため。
3.  経営者として、「この契約書の注意点を教えて」と相談したい。弁護士に聞くほどでもないが不安だから。
4.  経営者として、スマホからでも操作したい。現場や移動中に使うため。
5.  経営者として、自分のAPIキーを使いたい。コストを自分でコントロールするため。
6.  経営者として、過去の書類を検索したい。「先月の○○社の見積書どこだっけ？」をなくすため。
7.  経営者として、日報を音声で入力したい。キーボードが苦手だから。
8.  経営者として、AIが作った書類をプレビューしてから確定したい。間違いがあると信用問題だから。
9.  経営者として、月額の利用料を事前に知りたい。予算オーバーが怖いから。
10. 経営者として、データが安全に管理されていると安心したい。顧客情報を扱うから。

**各画面詳細:**

*   **ユーザー登録/ログイン画面**:
    *   新規登録、ログイン機能 (Supabase Auth)
    *   パスワードリセット
*   **ダッシュボード**:
    *   各機能へのナビゲーションリンク (チャット、レポート、書類、設定)
    *   簡単な利用状況サマリー (未着手タスク数、最新レポートなど)
*   **チャットアシスタント画面**:
    *   メッセージ入力フィールド
    *   AIからの応答表示エリア
    *   会話履歴表示 (セッション管理)
    *   `POST /api/chat`, `GET /api/chat/history` を利用
*   **レポート生成画面**:
    *   ファイルアップロードエリア (ドラッグ&ドロップ対応)
    *   過去のレポート一覧表示
    *   `POST /api/report/upload`, `GET /api/report/list` を利用
*   **レポート生成指示画面**:
    *   アップロードされたファイル名表示
    *   レポート生成指示入力フィールド (自然言語)
    *   「生成」ボタン
    *   `POST /api/report/generate` を利用
*   **レポート結果表示画面**:
    *   生成されたレポート内容の表示
    *   PDF/Markdownダウンロードボタン
    *   `GET /api/report/:id` を利用
*   **書類生成画面**:
    *   テンプレート選択リスト (見積書、請求書、お礼状)
    *   過去に生成した書類の一覧表示
    *   `GET /api/document/list` を利用
*   **書類情報入力画面**:
    *   選択されたテンプレートに応じた入力フォーム (例: 会社名、品目、金額など)
    *   自然言語での入力補助機能
*   **書類プレビュー画面**:
    *   AIが生成した書類のプレビュー表示
    *   PDF出力ボタン
    *   `POST /api/document/generate`, `GET /api/document/:id` を利用
*   **設定画面**:
    *   APIキー設定、プロフィール編集、プラン管理へのリンク
*   **APIキー管理画面**:
    *   BYOK (Bring Your Own Key) のAPIキー入力・保存機能
    *   `user_settings` テーブル (`docs/implementation-progress.md` 参照) を利用
*   **プロフィール編集画面**:
    *   ユーザー名の変更、メールアドレスの表示など
*   **プラン詳細画面**:
    *   現在のプラン表示 (Free, Pro, BYOK)
    *   プランアップグレードの案内 (Phase 2以降)

## 7. 非機能要件

`docs/product-proposal.md` と `docs/implementation-plan.md` の内容を統合・詳細化します。

*   **レスポンス**:
    *   チャット応答: 3秒以内
    *   レポート生成: 10秒以内 (ファイルサイズに依存)
    *   書類生成: 5秒以内
    *   画面初期ロード (LCP): 2秒以内
*   **可用性**: 99.5%以上
*   **セキュリティ**:
    *   データ暗号化 (at-rest, in-transit)
    *   SupabaseのRLS (Row Level Security) を利用し、ユーザーデータへのアクセスを厳密に制御
    *   APIキーは暗号化して保存し、厳重に管理
    *   SOC2準拠を目指す
*   **スケーラビリティ**: Cloudflare WorkersおよびSupabaseによる自動スケーリング
*   **対応ブラウザ**: Chrome, Safari, Edge (最新2バージョン)
*   **スマホ対応**: iOS Safari, Android Chrome に対応したレスポンシブUI
*   **データ保持**: Freeプランは30日、Proプランは90日 (Phase 2で導入)
*   **監査ログ**: 重要な操作ログ (ファイルアップロード、書類生成など) を記録 (Phase 2で導入)
