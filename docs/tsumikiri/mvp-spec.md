## 1. プロダクト概要

ツミキリは、中小企業の経営者が「事務作業の山」から解放されるためのAIアシスタント。自然言語で指示するだけで、日常の事務作業をAIが代行する。

## 2. MVP機能定義

Q1四半期計画に基づき、以下の3つのMVP機能を定義する。

### 2.1. AIレポート生成

- **機能概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することでAIがデータを分析し、レポートを生成する。
- **ユーザーストーリー**:
    - 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
    - 経営者として、月ごとの売上推移をグラフで表示してほしい。事業の状況を視覚的に把握するため。
    - 経営者として、部門別の利益率を分析してほしい。どの部門に注力すべきか判断するため。
    - 経営者として、生成されたレポートをPDFでダウンロードしたい。社内共有や報告に使うため。
    - 経営者として、過去に生成したレポートを一覧で確認したい。後から参照できるようにするため。
    - 経営者として、レポート生成時に使用するデータ範囲（例: 特定の期間、特定の顧客）を指定したい。必要な情報だけを抽出するため。
- **画面遷移**:
    `ダッシュボード` → `レポート生成`
        ├── `ファイルアップロード` (CSV/Excel)
        ├── `分析指示入力` (自然言語)
        └── `レポート表示` → `ダウンロード` (PDF/Markdown)
- **データモデル**:
    - `reports` テーブル: レポート履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `title` (VARCHAR)
        - `file_name` (VARCHAR)
        - `file_url` (TEXT)
        - `prompt` (TEXT)
        - `result` (TEXT)
        - `created_at` (TIMESTAMPTZ)
- **APIエンドポイント**:
    - `POST /api/report/generate`: レポート生成
    - `GET /api/reports/history`: レポート履歴取得
    - `GET /api/reports/:reportId`: 特定レポート詳細取得
- **非機能要件**:
    - 大容量ファイル（例: 100MBまで）のアップロードに対応
    - レポート生成は30秒以内

### 2.2. テンプレート書類生成

- **機能概要**: 見積書・請求書・お礼状などのテンプレートを用意し、自然言語またはフォーム入力で情報を流し込み、書類を生成する。
- **ユーザーストーリー**:
    - 経営者として、「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」と言いたい。書類作成に30分かかるのを3分にするため。
    - 経営者として、作成した請求書をPDFで出力したい。取引先に送るため。
    - 経営者として、よく使う顧客情報をテンプレートに自動入力してほしい。入力の手間を省くため。
    - 経営者として、複数のテンプレートから最適なものを選びたい。用途に合わせて使い分けるため。
    - 経営者として、AIが作った書類をプレビューしてから確定したい。間違いがあると信用問題だから。
    - 経営者として、作成した書類をメールで直接送信したい。手作業を減らすため。
    - 経営者として、よく使う定型文を登録しておきたい。書類作成の効率を上げるため。
- **画面遷移**:
    `ダッシュボード` → `書類生成`
        ├── `テンプレート選択`
        ├── `情報入力` (自然言語 or フォーム)
        └── `プレビュー` → `PDF出力`
- **データモデル**:
    - `documents` テーブル: 生成された書類履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `template_id` (UUID)
        - `title` (VARCHAR)
        - `content` (TEXT)
        - `generated_file_url` (TEXT)
        - `created_at` (TIMESTAMPTZ)
    - `templates` テーブル: テンプレート情報を保存。
        - `id` (UUID)
        - `name` (VARCHAR)
        - `type` (VARCHAR)
        - `content` (TEXT)
        - `created_at` (TIMESTAMPTZ)
- **APIエンドポイント**:
    - `POST /api/document/generate`: 書類生成
    - `GET /api/templates`: テンプレート一覧取得
    - `GET /api/documents/history`: 書類履歴取得
- **非機能要件**:
    - PDF出力の正確性
    - テンプレートの種類拡充（MVPでは3種類）

### 2.3. チャットアシスタント

- **機能概要**: 何でも聞ける経営者向けAIチャット。事業に関する質問、アドバイス、文章作成など。過去の会話履歴を保持する。
- **ユーザーストーリー**:
    - 経営者として、「この契約書の注意点を教えて」と相談したい。弁護士に聞くほどでもないが不安だから。
    - 経営者として、事業計画についてアドバイスが欲しい。壁打ち相手として使いたいから。
    - 経営者として、顧客へのクレーム対応メールの文面を作成してほしい。丁寧な文章を素早く作りたいから。
    - 経営者として、過去の会話履歴を参照したい。以前のやり取りを忘れてしまっても確認できるようにするため。
    - 経営者として、スマホからでもチャットを使いたい。移動中や外出先でも相談できるようにするため。
    - 経営者として、AIとの会話で重要なポイントをメモしておきたい。後から見返せるようにするため。
    - 経営者として、AIの回答が分かりにくい時に、より詳しく説明してほしい。理解を深めるため。
- **画面遷移**:
    `ダッシュボード` → `チャット`
        ├── `チャット入力`
        └── `会話履歴表示`
- **データモデル**:
    - `chat_messages` テーブル: 会話履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `role` (VARCHAR)
        - `content` (TEXT)
        - `created_at` (TIMESTAMPTZ)
- **APIエンドポイント**:
    - `POST /api/chat`: チャット送信・AI応答取得
    - `GET /api/chat/history`: 会話履歴取得
    - `GET /api/chat/history/:sessionId`: 特定セッションの履歴取得
- **非機能要件**:
    - レスポンスは3秒以内
    - 過去の会話履歴を元にしたコンテキスト維持

## 3. 共通非機能要件

- **認証**: Supabase Authによるユーザー認証
- **対応ブラウザ**: Chrome, Safari, Edge（最新2バージョン）
- **スマホ**: iOS Safari, Android Chrome 対応
- **セキュリティ**: データ暗号化（at-rest, in-transit）、SOC2準拠を目指す
- **BYOK**: 自分のAPIキーを利用できる機能
