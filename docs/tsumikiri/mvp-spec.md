## 1. プロダクト概要

ツミキリは、中小企業の経営者が「事務作業の山」から解放されるためのAIアシスタント。自然言語で指示するだけで、日常の事務作業をAIが代行する。

## 2. MVP機能定義

Q1四半期計画に基づき、以下の3つのMVP機能を定義する。

### 2.1. AIレポート生成

- **機能概要**: CSVまたはExcelファイルをアップロードし、自然言語で指示することでAIがデータを分析し、レポートを生成する。
- **ユーザーストーリー**:
    - 経営者として、CSVをアップロードして「今月の売上まとめて」と言いたい。事務員に頼む手間を省くため。
    - 経営者として、月ごとの売上推移をグラフで表示してほしい。事業の状況を視覚的に把握するため。
    - 経営者として、部門別の利益率を分析してほしい。どの部門に注力すべきか判断するため。
    - 経営者として、生成されたレポートをPDFでダウンロードしたい。社内共有や報告に使うため。
    - 経営者として、過去に生成したレポートを一覧で確認したい。後から参照できるようにするため。
    - 経営者として、レポート生成時に使用するデータ範囲（例: 特定の期間、特定の顧客）を指定したい。必要な情報だけを抽出するため。
    - 経営者として、AIが生成したレポートの内容について、「この部分をもっと詳しく説明して」と追加で質問したい。レポート内容を深く理解し、疑問点を解消するため。
    - 経営者として、定期的に（例: 毎月1日）特定のCSVファイルから自動でレポートを生成し、メールで受け取りたい。定型業務を自動化し、報告漏れを防ぐため。
    - 経営者として、生成されたレポートを、グラフの種類（棒グラフ、円グラフなど）や表示項目を自由にカスタマイズして出力したい。見せたい情報に合わせて柔軟に調整するため。
- **画面遷移**:
    `ダッシュボード` → `レポート生成`
        ├── `ファイルアップロード` (CSV/Excel)
        ├── `分析指示入力` (自然言語)
        └── `レポート表示` → `ダウンロード` (PDF/Markdown)
- **データモデル**:
    - `reports` テーブル: レポート履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `title` (VARCHAR)
        - `file_name` (VARCHAR)
        - `file_url` (TEXT)
        - `prompt` (TEXT)
        - `result` (TEXT)
        - `created_at` (TIMESTAMPTZ)
- **APIエンドポイント**:
    - `POST /api/report/generate`: レポート生成
    - `GET /api/reports/history`: レポート履歴取得
    - `GET /api/reports/:reportId`: 特定レポート詳細取得
- **非機能要件**:
    - 大容量ファイル（例: 100MBまで）のアップロードに対応
    - レポート生成は30秒以内

### 2.2. テンプレート書類生成

- **機能概要**: 見積書・請求書・お礼状などのテンプレートを用意し、自然言語またはフォーム入力で情報を流し込み、書類を生成する。
- **ユーザーストーリー**:
    - 経営者として、「○○建設さんへ、屋根修理の見積書を作って。金額は35万円」と言いたい。書類作成に30分かかるのを3分にするため。
    - 経営者として、作成した請求書をPDFで出力したい。取引先に送るため。
    - 経営者として、AIが作った書類をプレビューしてから確定したい。間違いがあると信用問題だから。
    - 経営者として、よく使う文言や定型情報をテンプレートに登録しておきたい。毎回入力する手間を省くため。
    - 経営者として、複数のテンプレートの中から用途に合ったものを選択したい。多様なビジネスシーンに対応するため。
    - 経営者として、作成した見積書や請求書に、自社の社判や担当者印の画像を挿入したい。紙の書類と同様の信頼性を確保するため。
    - 経営者として、一度作成した書類（例: 見積書）を元に、内容を一部変更して別の顧客向けの書類（例: 請求書）を簡単に作成したい。類似書類の作成効率を向上させるため。
- **画面遷移**:
    `ダッシュボード` → `書類生成`
        ├── `テンプレート選択`
        ├── `情報入力` (自然言語 or フォーム)
        └── `プレビュー` → `PDF出力`
- **データモデル**:
    - `documents` テーブル: 生成された書類履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `type` (VARCHAR, e.g., 'invoice', 'quotation')
        - `title` (VARCHAR)
        - `content` (TEXT)
        - `pdf_url` (TEXT)
        - `created_at` (TIMESTAMPTZ)
    - `templates` テーブル: ユーザー定義テンプレートを保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `name` (VARCHAR)
        - `content` (TEXT)
        - `type` (VARCHAR)
- **APIエンドポイント**:
    - `POST /api/document/generate`: 書類生成
    - `GET /api/documents/history`: 書類履歴取得
    - `GET /api/documents/:documentId`: 特定書類詳細取得
    - `POST /api/template/upload`: テンプレートアップロード
    - `GET /api/templates`: テンプレート一覧取得
- **非機能要件**:
    - 書類生成は5秒以内
    - 複数形式（PDF, Word, Excel）での出力対応（Phase 2）

### 2.3. チャットアシスタント

- **機能概要**: 経営者のあらゆる質問や相談に対応するAIチャット。過去の会話履歴を保持し、コンテキストを理解した応答が可能。
- **ユーザーストーリー**:
    - 経営者として、「この契約書の注意点を教えて」と相談したい。弁護士に聞くほどでもないが不安だから。
    - 経営者として、事業に関するアドバイスやアイデアをAIに相談したい。一人で抱え込まずに壁打ち相手がほしいから。
    - 経営者として、過去の会話履歴を振り返りたい。重要な情報を忘れないようにするため。
    - 経営者として、スマホからでもチャットで相談したい。場所を選ばずに利用するため。
    - 経営者として、AIが提供する情報が最新であることを期待する。常に正確な情報に基づいた判断を行いたいため。
- **画面遷移**:
    `ダッシュボード` → `チャット`
        ├── `チャット入力`
        └── `会話履歴表示`
- **データモデル**:
    - `chat_messages` テーブル: 会話履歴を保存。
        - `id` (UUID)
        - `user_id` (UUID)
        - `role` (VARCHAR, e.g., 'user', 'assistant')
        - `content` (TEXT)
        - `created_at` (TIMESTAMPTZ)
- **APIエンドポイント**:
    - `POST /api/chat`: チャット送信・AI応答取得
    - `GET /api/chat/history`: 会話履歴取得
    - `GET /api/chat/history/:sessionId`: 特定セッションの履歴取得
- **非機能要件**:
    - チャット応答は3秒以内
    - 会話履歴の永続化
    - 堅牢な認証・認可システム
