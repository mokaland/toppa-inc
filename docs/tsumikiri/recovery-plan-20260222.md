# リカバリープラン - 2026年2月22日

Tech Lead (マルコ・ロッシ) の継続的な業務不履行によりプロジェクトが一時的に停止しましたが、本日より以下のリカバリープランに基づき開発を再開します。

## 役割の再定義

### Tech Lead (マルコ・ロッシ)
- **現在の状況**: 一貫した業務不履行とリカバリープラン未提出のため、Tech Leadとしての責任は無期限に停止されます。
- **今後の対応**: 全ての技術実装タスクは一時的に「Builder」ロールに割り当てられます。BuilderはProduct Leadの直接的な指導のもと、暫定的なTech Leadとして機能します。

### Builder (マルコ・ロッシ)
- **役割**: 停止されたTech Leadの職務を事実上引き継ぎ、全ての技術実装、テスト、CI/CDタスクを担当します。
- **責務**: 極度の注意と勤勉さをもって業務にあたり、既存のアーキテクチャガイドラインを厳守し、全てのチェックをパスするコードを保証しなければなりません。Product Leadに対し、進捗を直接報告します。

## リカバリープラン詳細

1.  **開発の即時再開**: 「Builder」ロールの下で、優先度の高い開発タスクを再開します。Builderは、Product Leadからの指示に基づき、割り当てられたタスクにのみ集中します。
2.  **明確なタスクの優先順位付け**: Product Lead (高橋レン) は、Builderに対し、明確で優先順位付けされたタスクを提供します。Builderは、Product Leadから割り当てられたタスクのみを実施します。
3.  **厳格なガイドライン順守**: Builderは、コードスタイル、テスト、コミット手順を含む `AGENTS.md` およびプロジェクト固有の全てのガイドラインを厳格に遵守します。
4.  **日次進捗報告**: Builderは、タスクの進捗状況について、Product Leadに対し日次で報告します。
5.  **コード品質とテストへの注力**: 全ての機能実装には、包括的な単体テストおよび結合テストが含まれ、コミット前に `tsc --noEmit` および `npm run build` の全てのチェックをパスする必要があります。
6.  **将来のTech Lead再評価**: プロジェクトが軌道に戻り、安定した開発リズムが確立された後、長期的なTech Leadの役割は再評価されます。
