## 機能1: AIレポート生成 (MVP-1)

### Theme: 事務員に頼まなくても、手元の売上データを即座に可視化・要約できる

#### User Story 1.1: CSVファイルのアップロード
- **As a** 経営者 (田中 誠一)
- **I want to** PCにある売上データのCSVファイルを、ブラウザの画面にドラッグ＆ドロップで簡単にアップロードしたい
- **So that** 面倒なファイル選択ダイアログを使わずに、素早く分析を始められる

**Acceptance Criteria:**
- [ ] ドラッグ＆ドロップでファイルがアップロードできる
- [ ] ファイル選択ボタンからもアップロードできる
- [ ] アップロード中は進捗がわかるローディング表示がある
- [ ] CSV以外のファイル（例: .xlsx, .jpg）をアップロードしようとすると、「対応しているファイル形式はCSVのみです」というエラーメッセージが表示される
- [ ] 5MBを超えるファイルをアップロードしようとすると、「ファイルサイズは5MB以下にしてください」というエラーメッセージが表示される

#### User Story 1.2: 自然言語でのレポート生成指示
- **As a** 経営者 (佐藤 美咲)
- **I want to** アップロードしたCSVデータに対して、「4月の商品Aと商品Bの売上を比較して」のような曖昧な日本語で指示を出したい
- **So that** Excelのピボットテーブルや関数を覚えなくても、欲しい答えがすぐに手に入る

**Acceptance Criteria:**
- [ ] テキストエリアに自然言語で指示を入力できる
- [ ] 「生成」ボタンを押すと、バックエンドのAIにCSVデータと指示プロンプトが送信される
- [ ] 処理中はボタンが非活性化され、スピナーが表示される

#### User Story 1.3: レポートの表示とダウンロード
- **As a** 経営者 (田中 誠一)
- **I want to** AIが生成したレポートを、箇条書きや簡単な表でまとめられた見やすい形式で画面上で確認したい
- **So that** 分析結果の要点を素早く把握し、次のアクションを考えられる

**Acceptance Criteria:**
- [ ] AIからの応答がMarkdown形式で整形されて画面に表示される
- [ ] レポートには、要点、分析結果、今後の提案などが含まれる
- [ ] 「ダウンロード」ボタンを押すと、表示されているレポートがMarkdownファイル（`.md`）としてダウンロードできる
- [ ] AIの処理が失敗した場合は、「レポートの生成に失敗しました。もう一度お試しください」というメッセージが表示される

## 機能2: チャットアシスタント (MVP-3)

### Theme: 経営の悩みをいつでも相談できる、頼れるAI壁打ち相手がいる

#### User Story 2.1: 経営に関する相談
- **As a** 経営者 (佐藤 美咲)
- **I want to** 「新しいキャンペーンのアイデアを5つ出して」や「従業員のモチベーションを上げるには？」のように、経営に関する悩みをチャットで相談したい
- **So that** 一人で抱え込まずに、客観的な視点やアイデアを得られる

**Acceptance Criteria:**
- [ ] チャット入力欄に質問を入力し、送信できる
- [ ] AIからの回答が、数秒以内に画面に表示される
- [ ] 過去のやり取りが画面上に保持され、文脈を維持した会話ができる

*(注: MVP-2 テンプレート書類生成はPhase 1の実装スコープから除外するわけではなく、まずはMVP-1とMVP-3のコア機能から着手することを推奨)*
