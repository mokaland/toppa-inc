# コンテンツ戦略 - TOPPA Inc.

## 戦略 Overview

TOPPA Inc.は「中小企業の"詰み"をAIで突破する」というミッションのもと、以下の展開を行う。

## 展開フェーズ

### Phase 1: 認知獲得（現在）
- ターゲット: 中小企業の経営者
- 目的: "詰み"という概念的課題とTOPPA Inc.の解決策を認知させる
- 主なチャネル: X（旧Twitter）、YouTube、note、Zenn

### Phase 2: 信頼構築
- ツミキリのβ版を提供し、実際の課題解決事例を作る
- 事例をコンテンツ化し口碑で広げる

### Phase 3: 拡大
- 第2弾、第3弾とプロダクトをリリース
- エコシステム形成

## ターゲット詳細

| 属性 | 詳細 |
|---|---|
| 年代 | 40-60代 |
| 職種 | 中小企業経営 者・取締役 |
| 課題 | 日々の事務作業に時間を奪われる |
| ITリテラシー | 低〜中 |
| 情報取得 | X、YouTube、経営者向けメディア |
